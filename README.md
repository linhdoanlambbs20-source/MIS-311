# Supermarket Sales Data Analysis

## Project Overview
This project analyses supermarket sales transactions using Excel and Pivot Tables to identify sales trends and customer purchasing behaviour.

## Dataset Description
The dataset contains supermarket transaction records, including city, customer type, product category, quantity sold, and total sales.

## Data Cleaning
- Removed missing values
- Checked duplicate rows
- Prepared clean dataset for analysis

## Descriptive Statistics
Descriptive statistics were performed for quantity and total_price to summarise customer purchasing behaviour and transaction values.

## Key Insights

### Insight 1
Fruits generated the highest total sales among all product categories, indicating strong customer demand.

### Insight 2
Chicago recorded the highest total sales, making it the strongest-performing city.

## Tools Used
- Microsoft Excel
- Pivot Table
- Charts
- Descriptive Statistics
